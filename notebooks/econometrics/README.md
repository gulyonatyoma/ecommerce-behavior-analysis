# Econometric Analysis

## Цель

Исследовать факторы, связанные с вероятностью совершения покупки, и оценить влияние характеристик пользователя и товара на покупательское поведение.

---

## Анализируемая переменная

Основная зависимая переменная:

purchase_flag

0 — пользователь не совершил покупку.

1 — пользователь совершил покупку.

---

## Модели

Используемые модели:

- Linear Probability Model;
- Logistic Regression;
- Probit Model.

---

## Возможные факторы

User Features:

- количество событий;
- количество сессий;
- активность пользователя;
- история взаимодействий.

Product Features:

- цена;
- категория;
- характеристики товара.

Behavioral Features:

- количество действий перед покупкой;
- время взаимодействия;
- глубина просмотра.

---

## Проверки

Включают:

- анализ коэффициентов;
- статистическую значимость;
- проверку устойчивости результатов;
- сравнение моделей.

---

## Результат

Итогом должны стать:

- факторы, связанные с покупкой;
- интерпретация результатов моделей;
- ограничения анализа;
- выводы для бизнеса.
