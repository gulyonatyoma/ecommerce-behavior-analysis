# Product Analytics

## Цель

Исследовать поведение пользователей внутри продукта и понять, какие этапы пользовательского пути влияют на совершение покупки.

---

## Анализы

### Funnel Analysis

Исследование пользовательской воронки:

view

↓

cart

↓

purchase


Основные метрики:

- количество пользователей на каждом этапе;
- conversion rate;
- drop-off rate;
- переходы между этапами.

---

### Product Performance Analysis

Анализ эффективности товаров и категорий.

Метрики:

- количество просмотров;
- количество добавлений в корзину;
- количество покупок;
- revenue;
- conversion rate.

---

## Результат

В результате должны быть получены:

- основные точки потери пользователей;
- наиболее эффективные товары и категории;
- рекомендации по улучшению продукта.
