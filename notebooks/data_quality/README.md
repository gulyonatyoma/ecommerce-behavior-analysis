# Data Quality Analysis

Цель:

Проверить качество исходных данных перед проведением анализа.

Включает:

- структуру данных;
- пропущенные значения;
- дубликаты;
- типы данных;
- распределение событий;
- временной диапазон;
- базовые проверки качества.

Результат:

Подготовленный датасет для дальнейшей аналитики.
