# Customer Analytics

## Цель

Исследовать поведение пользователей, определить различия между сегментами клиентов и понять особенности покупательского поведения.

---

## Анализы

### Buyer vs Non-Buyer Analysis

Сравнение пользователей:

- совершивших покупку;
- не совершивших покупку.

Анализируется:

- количество событий;
- количество сессий;
- активность;
- взаимодействие с товарами.

---

### RFM Segmentation

Сегментация пользователей по:

Recency:

- время с последней активности.

Frequency:

- частота взаимодействия.

Monetary:

- сумма покупок.

---

### Cohort Analysis

Исследование:

- удержания пользователей;
- повторных покупок;
- изменения поведения во времени.

---

## Результат

Итогом должны стать:

- пользовательские сегменты;
- описание поведения групп;
- рекомендации по работе с клиентами.
