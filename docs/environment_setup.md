# Environment Setup

## Установка окружения

Создать виртуальное окружение:

python -m venv venv


Активировать окружение:

Windows:

venv\Scripts\activate


Mac/Linux:

source venv/bin/activate


Установить зависимости:

pip install -r requirements.txt


---

## Переменные окружения

Создать локальный файл:

.env


Скопировать настройки из:

.env.example


Заполнить необходимые значения.


---

## Проверка установки

Проверить Python:

python --version


Проверить библиотеки:

pip list
