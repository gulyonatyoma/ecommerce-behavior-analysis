# Feature Engineering

Папка содержит логику подготовки признаков.

Используется для:

- создания пользовательских признаков;
- подготовки ML features;
- агрегирования данных;
- преобразования данных для моделей.

Будущие модули:

- user features;
- product features;
- behavioral features.

Реализация будет добавлена после определения структуры данных.
