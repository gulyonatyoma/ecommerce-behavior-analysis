# Data Layer

Папка отвечает за работу с данными проекта.

Назначение:

- загрузка данных;
- подготовка данных;
- обработка данных;
- проверки качества данных.

Будущие модули:

- data loading;
- data validation;
- data preprocessing.

Реализация будет добавлена после определения структуры исходных данных.
