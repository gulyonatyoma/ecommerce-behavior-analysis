# Data Structure

Эта папка содержит данные проекта.

Данные разделены на три уровня:

- raw — исходные данные;
- interim — промежуточные данные после обработки;
- processed — готовые аналитические датасеты.

---

# raw/

Папка `raw` содержит исходные данные.

Примеры:

- пользовательские события;
- данные о товарах;
- транзакции;
- выгрузки из источников.

Правила:

- данные не изменяются;
- исходные файлы сохраняются в первоначальном виде;
- новые версии данных добавляются отдельными файлами.

---

# interim/

Папка `interim` содержит промежуточные результаты обработки.

Примеры:

- очищенные события;
- объединённые таблицы;
- временные датасеты после preprocessing.

Эти данные могут изменяться в процессе разработки.

---

# processed/

Папка `processed` содержит финальные аналитические датасеты.

Примеры:

- user-level dataset;
- session-level dataset;
- product-level dataset;
- ML feature dataset.

Эти данные используются для:

- аналитики;
- эконометрического моделирования;
- машинного обучения.

# Important Rules

Запрещено:

- хранить большие датасеты напрямую в GitHub;
- загружать персональные данные пользователей;
- изменять файлы в raw вручную.

Рекомендуется:

- хранить описание структуры данных;
- документировать изменения;
- использовать понятные названия файлов.
