# Purchase Propensity Model

ML-модель для прогнозирования вероятности покупки товара пользователем в течение следующих **7 дней**.

Модель работает на уровне пары **user–product** и использует историю поведения за предыдущие **30 дней**: просмотры, добавления в корзину, покупки, активность пользователя, популярность товара, цену, бренд, категорию и временные признаки.

Для обучения использовался `CatBoostClassifier`. Данные разделялись по времени на train, validation и test, а дополнительная проверка проводилась на отдельной выборке полностью новых пользователей.

На независимых тестовых данных модель показала **ROC-AUC ≈ 0.90**. В top-10% взаимодействий с максимальным прогнозом модели содержится около **71% будущих покупок**.

## Files

### `purchase_propensity_v1.cbm`

Обученная модель `CatBoostClassifier` в нативном формате CatBoost.

Файл содержит структуру и веса обученных деревьев и может быть загружен без повторного обучения модели.

### `purchase_propensity_metadata.pkl`

Метаданные, необходимые для корректного использования модели:

* список признаков и их порядок;
* список категориальных признаков;
* название target;
* prediction horizon — 7 дней;
* history window — 30 дней.

Файл нужен для подготовки новых данных в том же формате, который использовался при обучении.

### `eCommerce_ML.ipynb`

Основной Jupyter Notebook проекта, содержащий весь ML-пайплайн:

* подключение к ClickHouse;
* загрузку подготовленных ML-витрин;
* подготовку train / validation / test;
* baseline-модели;
* обучение CatBoost;
* расчёт ROC-AUC, PR-AUC и Lift;
* проверку на независимой выборке новых пользователей;
* анализ feature importance и SHAP;
* исследование и интерпретацию результатов модели.
